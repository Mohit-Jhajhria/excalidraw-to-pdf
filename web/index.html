How to convert Excalidraw to PDF

  1. Save from Excalidraw

    Open the menu and choose Save to… to get a .excalidraw file.

  2. Open it here

    Drop the file on this page. It is split into one page for each slide.

  3. Fix the cuts

    Click between two slides to add a cut line. Drag a line to move it, or click its × to remove it.

  4. Download

    Untick any page you do not want, then press Download PDF.

Questions and answers

How do I convert an Excalidraw file to PDF?

In Excalidraw, open the menu and choose Save to… to get a .excalidraw file. Open that file on this page, check the list of pages, and press Download PDF.

How do I make a multi-page PDF from one Excalidraw drawing?

When you open your file, the tool already makes one page for each slide. To change the split, click between two slides to add a cut line. Each line starts a new page. Drag a line to move it, or click its × to remove it.

Why do my slides look small on a big blank page?

That happens when a converter uses the whole drawing area as the page size. This tool cuts every page to just its own content, so a slide fills its page with only a very small margin.

Is my Excalidraw file uploaded to a server?

No. Everything runs in your browser, so your drawing never leaves your computer.

Is the Excalidraw to PDF converter free?

Yes. It is free, needs no account, and adds no watermark. The code is on GitHub and is free for personal and non-commercial use.

Can I select and copy text in the PDF?

Not at the moment. Each page is saved as a sharp picture, so text and drawings look exactly like they do in Excalidraw, but the text cannot be selected.

Which browsers does it work in?

It works best in Google Chrome.

Need selectable text in your PDF?

The website saves each page as a sharp picture — text looks perfect but cannot be selected or copied. If you need text that can be highlighted, use the command-line version instead: it produces a fully vector PDF where text is real and searchable.

  1. Install

    Make sure you have Node.js 18+ and Chrome or Edge installed, then run npm install inside the project folder.

  2. Build

    Run npm run build once to compile the renderer into dist/bundle.js.

  3. Convert

    Run node bin/excalidraw2pdf.mjs my-slides.excalidraw. A vector PDF appears next to the input file. Use --help to see all options.
